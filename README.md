# 🚀 Personal Web Portfolio & Developer Showcase

A modern, responsive personal portfolio built with **React**, **Styled Components**, and **Framer Motion**. This site showcases my professional experience, key engineering projects, and technical skill set, along with an integrated email contact form.

🔗 **Live Demo:** [https://hisnameisrehd.github.io/web-portfoliov2/](https://hisnameisrehd.github.io/web-portfoliov2/)

---

## ✨ Features

- **Dynamic Animations:** Smooth scroll and reveal transitions powered by `framer-motion` and `react-intersection-observer`.
- **Interactive Contact Form:** Instant email delivery integrated directly with **EmailJS**.
- **Responsive Design:** Mobile-first layout using custom Styled Components.
- **Career Timeline:** Structured showcase of career progression, technical achievements, and key projects.
- **Environment Variable Protection:** Clean separation of API keys and client configurations.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3
- **Styling:** Styled Components
- **Animations:** Framer Motion
- **Integrations:** EmailJS
- **Deployment:** GitHub Pages (`gh-pages`)
